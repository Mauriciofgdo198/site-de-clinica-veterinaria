# Site de Clínica Veterinária

Site institucional responsivo da Clínica Vet, desenvolvido com HTML, CSS e JavaScript puro.

## Desenvolvimento local

Abra `index.html` no navegador. Não há dependências nem etapa de build.

## Organização

```text
.
├── assets/                  # Imagens, ilustrações e identidade visual
├── css/styles.css            # Layout, responsividade e animações
├── js/data/services.js       # Catálogo de serviços
├── js/main.js                # Interações da página
└── index.html                # Estrutura principal
```

## Responsividade

- Desktop: banner horizontal do rodapé.
- Mobile e tablet retrato: banner vertical até `900px`.
- Serviços: grade completa em telas menores, sem rolagem horizontal.

## Publicação

O projeto é compatível com hospedagem estática e pode ser publicado diretamente na Vercel usando a raiz do repositório.
